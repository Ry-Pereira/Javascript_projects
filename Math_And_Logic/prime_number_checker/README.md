# 🔢✨🟦 Prime Number Checker 🟦✨🔢

## 📌🌟 Overview ✨

This project is a JavaScript-based program 💻🟨 that checks whether a user-provided number is a **Prime Number** 🔢 or a **Composite Number** 📊.

The program uses loops 🔁, conditionals ⚡, functions 🧠, and input validation ✔️ to determine whether the entered number is divisible only by 1 and itself.

# 📡⚙️ Program Logic 🧩

The program works by:

1️⃣ Displaying a welcome message 👋  

2️⃣ Showing a menu with options 📋  

3️⃣ Prompting the user to:
   - Check a number 🔢
   - Exit the program 🚪

4️⃣ Validating the entered number ✔️  

5️⃣ Checking if the number is divisible by values other than:
   - `1`
   - itself

6️⃣ Determining whether the number is:
   - Prime ✔️
   - Composite 📊

7️⃣ Displaying the result in the console 💻✨

# 🔢📘 Prime Number Rules ✨

A prime number:
- Has exactly two factors:
  - `1`
  - itself

Examples of prime numbers:
```text
2, 3, 5, 7, 11, 13, 17
```

Examples of composite numbers:
```text
4, 6, 8, 9, 10, 12
```
