# 📄 FizzBuzz Number Sequence Program

## 📌 Overview

This project is a JavaScript-based program that generates a sequence of numbers between a user-defined start and end range, then evaluates each number based on classic FizzBuzz rules.

The program prompts the user for input and determines whether each number in the sequence is:

- **Fizz** → divisible by 3  
- **Buzz** → divisible by 5  
- **FizzBuzz** → divisible by both 3 and 5  
- Or simply the number itself if none of the conditions apply

## 📡 Program Logic

The program works by:

1. Prompting the user to enter:
   - A **start number**
   - An **end number**

2. Generating a sequence from start to end using a recursive function  

3. For each number, checking:
   - If divisible by **3 and 5** → output `"FizzBuzz"`  
   - If divisible by **3** → output `"Fizz"`  
   - If divisible by **5** → output `"Buzz"`
