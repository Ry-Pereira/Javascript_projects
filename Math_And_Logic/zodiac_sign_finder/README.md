## 📌🌟 Overview ✨🔮

This project is a JavaScript-based program 💻🟨 that determines a user's **Zodiac Sign** ♈ based on their birth month 📅 and birth day 📆.

The program validates the user's date input ✔️, searches through a list of zodiac signs 🔍♈, and displays the matching zodiac sign along with its element 🌎🔥💨💧 and personality traits ✨🌟.

# 📡⚙️ Program Logic 🧩✨

The program works by:

1️⃣ Displaying a welcome message 👋🌟  

2️⃣ Prompting the user to enter:
   - Birth month 📅
   - Birth day 📆

3️⃣ Validating the date input ✔️⚠️
   - Month must be between `1-12`
   - Day must be between `1-31`

4️⃣ Creating a list of zodiac sign objects ♈♉♊✨  

5️⃣ Looping through all zodiac signs 🔁🌌  

6️⃣ Checking if the user's birth date falls within a zodiac sign range 🎯📊  

7️⃣ Displaying:
   - Zodiac sign name ♈🌟
   - Zodiac element 🌎🔥💨💧
   - Personality traits ✨💫

8️⃣ Displaying an error message if no valid zodiac sign is found ⚠️❌
