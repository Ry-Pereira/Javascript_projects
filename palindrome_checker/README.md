# 📄 Palindrome Checker Program

## 📌 Overview

This project is a JavaScript-based program that checks whether a user-provided input is a **palindrome**.

A palindrome is a word or phrase that reads the same **forward and backward** (e.g., "racecar", "madam").

The program prompts the user for input, reverses the string, and determines if it matches the original input.

## 🚀 Features

- Accepts string input from the user  
- Reverses the input string manually using a loop  
- Compares original and reversed strings  
- Identifies whether the input is a palindrome  
- Handles invalid input (very short strings)  
- Displays results in the console  

---

## 🛠️ Technologies Used

- JavaScript  
- Console input/output (`prompt`, `console.log`)  

---

## 📡 Program Logic

The program works by:

1. Displaying a welcome message  

2. Prompting the user to enter a string  

3. Checking the length of the input:
   - If ≤ 1, returns an invalid input message  

4. Reversing the string using a loop  

5. Comparing the reversed string with the original  

6. Returning:
   - `"a Palindrome!"` if both match  
   - `"not a Palindrome!"` if they do not match  

7. Displaying the result in the console  

8. Ending the program with a message
