# 🪨 📄 ✂️ Rock Paper Scissors Program

## 📌 Overview

This project is a JavaScript-based implementation of the classic **Rock, Paper, Scissors** game.

The program allows a user to play against the computer for **3 rounds**, where each round determines a winner based on standard game rules. At the end, the program declares the overall winner.

project-folder/

## 🚀 Features

- Play Rock, Paper, or Scissors against the computer  
- Randomized computer move selection  
- Input validation for user moves  
- Tracks scores across multiple rounds  
- Displays round-by-round results  
- Declares an overall game winner  

---

## 🛠️ Technologies Used

- JavaScript  
- Console input/output (`prompt`, `console.log`)  

---

## 📡 Program Logic

The program works by:

1. Displaying a welcome message  

2. Running a loop for 3 rounds  

3. For each round:
   - Prompting the user for a move  
   - Randomly generating the computer’s move  
   - Comparing moves using game rules:
     - Rock beats Scissors  
     - Paper beats Rock  
     - Scissors beats Paper  

4. Determining the result of each round:
   - User win  
   - Computer win  
   - Tie  
   - Invalid input (counts as a loss)  

5. Tracking scores for both user and computer  

6. Determining and displaying the overall winner  

7. Ending the program  

---

## ▶️ How to Run the Project

1. Ensure JavaScript is supported in your environment (Node.js recommended)

2. Run the program:
