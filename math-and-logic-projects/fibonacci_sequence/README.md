# 🔢🌀 Fibonacci Sequence Generator 💻✨

## 📌 Overview

This project is a JavaScript-based implementation of a recursive **Fibonacci Sequence Generator** 🔢.

The program allows users to generate Fibonacci numbers using recursion. It features a menu-driven interface, user input validation, and organized program flow using functions.

# 📡 Program Logic 🧠

The program works by:

1. 👋 Displaying a welcome message and menu

2. 📋 Allowing the user to:
   - ▶️ Generate a Fibonacci number
   - 🚪 Exit the program

3. 🔢 Asking the user for a positive integer

4. 🧠 Calculating the Fibonacci value recursively using:

```text
F(n) = F(n - 1) + F(n - 2)
```

5. 🔍 Validating user input:
   - ✅ Checks if input is a number
   - ❌ Rejects negative integers

6. 📤 Displaying the Fibonacci result

7. 🔁 Repeating until the user exits
