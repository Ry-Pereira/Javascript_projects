# 🔢 Even or Odd Program

## 📌 Overview

This project is a JavaScript-based program that determines whether a user-provided number is even, odd, or invalid. The program prompts the user to enter a number, processes the input, and returns a result based on its value.

Users can:
* Enter a number  
* Check if the number is even or odd  
* Receive feedback if the input is invalid

## 🚀 Features

* Determines if a number is even or odd  
* Handles invalid input cases  
* Uses modulus operator for calculation  
* Simple and easy-to-understand logic  
* Console-based user interaction  

---

## 🛠️ Technologies Used

* JavaScript  
* Console input/output (prompt + console.log)  
* Node.js or browser environment (with prompt support)  

---

## 📡 Program Logic

The program works by:

1. Prompting the user to enter a number  
2. Converting the input into an integer  
3. Using the modulus operator (`% 2`) to determine:
   * `0` → Even  
   * `1` → Odd  
4. Returning "Invalid" if the input does not meet conditions
