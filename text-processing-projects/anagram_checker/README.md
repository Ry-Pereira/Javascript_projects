# 🔤 Anagram Checker Program

## 📌 Overview

This project is a JavaScript-based Anagram Checker that determines whether two user-provided strings are anagrams of each other. An anagram is formed when two words or phrases contain the same letters in the same frequency, just arranged differently.

The program prompts the user for two inputs and evaluates whether they meet the criteria to be considered anagrams.

Users can:
* Enter two strings
* Compare letter counts between both inputs
* Receive a clear result indicating whether the strings are anagrams

* JavaScript  
* Console input/output (prompt + console.log)  
* Node.js or browser environment (with prompt support)  

---

## 📡 Algorithm Approach

The program determines anagrams by:

1. Checking if both strings have the same length  
2. Counting occurrences of each character in both strings  
3. Comparing character frequencies  
4. Returning a result based on the comparison
