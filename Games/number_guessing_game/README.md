# 🎯🔢 Number Guessing Game 🎮✨

## 📌 Overview

This project is a JavaScript-based implementation of a classic **Number Guessing Game** 🎲.

The program generates a random number between **1 and 100**, and the player attempts to guess the correct number. The game provides hints indicating whether the guess is **too high** 📈 or **too low** 📉 until the correct number is guessed.

# 📡 Program Logic 🧠

The program works by:

1. 👋 Displaying a welcome message and menu

2. 📋 Allowing the user to:
   - ▶️ Start the guessing game
   - 🚪 Exit the program

3. 🎲 Generating a random number between 1 and 100

4. 🔢 Asking the user to guess the number

5. 🔍 After every guess:
   - ✅ Checking if the input is valid
   - 📏 Checking if the guess is within range
   - 📉 Informing the user if the guess is too low
   - 📈 Informing the user if the guess is too high

6. 🔁 Repeating until the correct number is guessed

7. 🎉 Displaying a winning message when the player guesses correctly
