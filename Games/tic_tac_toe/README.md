# ⭕ ❌ Tic Tac Toe Program

## 📌 Overview

This project is a JavaScript-based implementation of the classic **Tic Tac Toe** game.

The program allows two players to play against each other in the console by taking turns placing Xs and Os on a 3x3 board. The game continues until one player wins or the board is full, resulting in a draw.

## 🚀 Features

- Two-player Tic Tac Toe gameplay  
- 3x3 game board  
- Turn-based player system  
- Detects row, column, and diagonal wins  
- Detects draw conditions  
- Displays the board after every move  
- Uses JavaScript classes and modules  

---

## 🛠️ Technologies Used

- JavaScript  
- ES6 Modules (`import` / `export`)  
- Console input/output (`prompt`, `console.log`)  

---

## 📡 Program Logic

The program works by:

1. Displaying a welcome menu  

2. Allowing the user to:
   - Start a new game  
   - Exit the program  

3. Asking both players for their names  

4. Creating a TicTacToeBoard object  

5. Alternating turns between Player X and Player O  

6. After every move:
   - Updating the board  
   - Displaying the board  
   - Checking for a winner  
   - Checking if the board is full  

7. Ending the game when:
   - A player wins  
   - The game ends in a draw

## ▶️ How to Run the Project

1. Ensure JavaScript is supported in your environment (Node.js recommended)

2. Run the program:
