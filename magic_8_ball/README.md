# 🎱 Magic 8 Ball Program

## 📌 Overview

This project is a JavaScript-based Magic 8 Ball program that simulates a classic fortune-telling toy. Users interact with a simple menu, enter a question, and receive a randomized response from the Magic 8 Ball.

Users can:
* Select options from a menu
* Enter a question prompt
* Receive a random Magic 8 Ball response
* Exit the program

---

## 🧱 Project Structure

project-folder/  
│  
├── main.js # Main entry point (menu system and user interaction)  
├── magic_8_ball_class.js # Magic8Ball class with response logic  
│  
└── README.md  

---

## 🚀 Features

* Interactive menu-driven program  
* Randomized Magic 8 Ball responses  
* Object-oriented design using a class  
* Continuous loop until user exits  
* Simple command-line interaction  

---

## 🛠️ Technologies Used

* JavaScript  
* Node.js (or compatible runtime with prompt support)  
* Console input/output  

---

## 📡 API Used

No external API is used in this project.  
All responses are stored locally within the Magic8Ball class as a predefined list of strings.
